# Dados, identidade, cobrança e certidões — serviços intermediáveis via API/reseller/white label (Brasil, 2026)

## KYC / biometria facial / liveness / antifraude / background check — preços e programas de parceiro

### Takeaway
Existem provedores diretos (Serpro Datavalid, unico, CAF/Certta, Neoway, BigDataCorp, idwall, Direct Data, Infosimples) com API real e documentada, mas **preço público e detalhado de reseller/margem é raro** — a maioria exige contato comercial. Os poucos números públicos concretos: Serpro Datavalid cobra R$ 4,50 por consulta de biometria facial bem-sucedida; BigDataCorp publica tabela de preços por faixa de volume para dados cadastrais básicos (R$ 0,033–0,040/consulta). idwall e Serasa Experian têm programas formais de revenda/marketplace, mas sem tabela pública de comissão (exceto o "Clube do Revendedor" da Serasa, com números concretos abaixo).

### Cited Findings
- Serpro Datavalid (biometria facial com engine própria, 99,9% de acurácia declarada) cobra **R$ 4,50 por consulta de validação facial bem-sucedida**, com free trial de 30 dias ou até 3.000 consultas gratuitas, e cancelamento sem custo — [Loja Serpro / CryptoID](https://cryptoid.com.br/criptografia-identificacao-digital-id-biometria/datavalid-agrega-servico-de-biometria-facial-do-serpro/); confirmado também em [Serpro](https://www.serpro.gov.br/menu/imprensa/Releases/serpro-lanca-tecnologia-de-biometria-facial). Clientes citados: Votorantim e Original (banco). API documentada em [apicenter.estaleiro.serpro.gov.br/documentacao/datavalid](https://apicenter.estaleiro.serpro.gov.br/documentacao/datavalid/en/).
- BigDataCorp publica **API de Preços** própria (gratuita de consultar) que devolve o valor exato de cada dataset por volume mensal antes da cobrança — [Guia API de Preços](https://docs.bigdatacorp.com.br/plataforma/docs/guia-api-de-pre%C3%A7os); [Requisição](https://docs.bigdatacorp.com.br/plataforma/reference/api-de-pre%C3%A7os-requisicao).
- BigDataCorp — dataset "Dados Básicos" (CPF, nome, data de nascimento, nome da mãe): **R$ 0,040 por consulta na faixa de 1–10.000 consultas/mês**, caindo para **R$ 0,033 na faixa de 500.001–1.000.000/mês** — [Tabela de preços](https://docs.bigdatacorp.com.br/apps/docs/tabela-de-pre%C3%A7os).
- BigDataCorp opera um **Data Marketplace** com datasets de parceiros integrados ao mesmo ecossistema/SLA/compliance da BigDataCorp, sugerindo um modelo de revenda de dados de terceiros dentro da própria plataforma — [Preços e transparência](https://docs.bigdatacorp.com.br/apps/docs/pre%C3%A7os-e-transpar%C3%AAncia).
- idwall (KYC/background check, +200 fontes de dados) oferece **dois modelos formais de parceria: Co-sell e Reseller**, sendo o Reseller o modelo em que o parceiro contrata e revende as soluções idwall através de uma plataforma de Marketplace — [GetApp Brasil](https://www.getapp.com.br/software/2063958/idwall) (nota: página é de terceiro/agregador, não site oficial da idwall — tratar como indicativo, não como fonte primária de números).
- idwall lançou um **marketplace de soluções antifraude** com parceiros iniciais incluindo LSEG (World-Check, due diligence global, +5 milhões de perfis), Neoway e DocuSign, ampliando o ecossistema de identidade digital via integração "drag and drop" — [CQCS](https://cqcs.com.br/noticia/idwall-revoluciona-o-mercado-com-lancamento-de-marketplace-de-solucoes-antifraude/); [Inforchannel](https://inforchannel.com.br/2024/04/15/novos-parceiros-ampliam-ecossistema-de-identidade-digital-da-idwall/); [Blog idwall — Parceiros no ecossistema](https://blog.idwall.co/parceiros-ecossistema-idwall/). Não há tabela pública de comissão para esse marketplace.
- API da idwall v2 é RESTful, endpoint base `https://api-v2.idwall.co`, autenticação por token no dashboard, respostas em JSON — [docs.idwall.co](https://docs.idwall.co/docs/api-how-to-use); Postman collection pública em [documenter.getpostman.com](https://documenter.getpostman.com/view/3967924/RW1dEx9b).
- **CAF (Combate à Fraude) foi rebatizada "Certta"** e se posiciona como hub "Know Your Everything" (onboarding, verificação de documento, KYC, KYB, prevenção de account takeover), com SDK/API/web integráveis — [Certta.ai](https://www.certta.ai/) e [TI Inside](https://tiinside.com.br/24/01/2023/caf-lanca-plataforma-de-validacao-de-identidade-digital/). Isso é um dado estrutural importante: quem procurar "CAF" hoje pode não achar preços porque a marca mudou.
- CAF/Certta recebeu **aporte de R$ 50 milhões** liderado pela L4 (fundo da B3), sinal de crescimento e possível abertura de canais de parceria — [Finsiders Brasil](https://finsidersbrasil.com.br/negocios-em-fintechs/aportes/caf-de-antifraude-recebe-r-50-milhoes-em-rodada-liderada-por-l4-fundo-da-b3/).
- CAF/Certta tem parceria estratégica de dados judiciais com a Judit (API judicial) para reforçar antifraude — descrita como parceria de dados que evolui em conjunto, não um simples uso de API — [Judit.io — estudo de caso](https://judit.io/blog/estudos-de-caso/dados-judiciais-antifraude-caf-judit-estudo-de-caso/).
- unico Check: biometria facial com selfie + foto do CPF, **99% de assertividade declarada, autentica 80% dos usuários já na primeira tentativa**, redução de até 40% dos custos operacionais de onboarding/validação de transações segundo a própria empresa — [unico.io/unicocheck/api-reconhecimento-facial](https://unico.io/unicocheck/api-reconhecimento-facial/). Sem preço público encontrado.
- Neoway oferece 4 soluções antifraude (Neoway Check — KYC/onboarding; Neoway Compliance — due diligence de empresas e pessoas; Neoway Watcher — monitoramento contínuo; Neoway Lawsuits — base de processos judiciais), com API para reconhecimento facial, OCR/documentoscopia e base de +300 mil fraudadores conhecidos — [Blog Neoway — soluções antifraude](https://blog.neoway.com.br/solucoes-antifraude/); [Blog Neoway — API](https://blog.neoway.com.br/api-neoway/). Sem preço público.
- Direct Data é posicionada como "DaaS" para **fintechs, PMEs e times de compliance que precisam de KYC/AML/PLD em escala**, com dois modelos de cobrança: **pré-pago** (sem contrato, sem mensalidade mínima, acesso imediato) e **pós-pago** (onboarding assistido, SLA contratual, suporte priorizado), com desconto progressivo por volume — [Direct Data — Preços](https://www.directd.com.br/precos) (página existe mas o conteúdo detalhado não pôde ser buscado por bloqueio de rede nesta pesquisa; resumo vem do snippet de busca).
- Direct Data é citada como **revendedora autorizada pelo CENPROT** para consulta de protestos IEPTB, agregando todos os estados brasileiros numa única chamada de API — [Direct Data — Protestos IEPTB](https://www.directd.com.br/protestos-ieptb).

### Inferences
- O mercado brasileiro de KYC/antifraude tem pelo menos 3 camadas de possível intermediação: (1) provedor original de dado público/registro (Serpro, cartórios), (2) agregador/DaaS que já revende esse dado tratado (BigDataCorp, Direct Data, Infosimples, Netrin), e (3) camada de "solução" com IA/orquestração (idwall, unico, CAF/Certta, Neoway) que por sua vez às vezes compra dado das camadas 1–2. Um ERP quer entrar como canal de distribuição da camada 2 ou 3 (não tentar ser camada 1), porque exige menor investimento técnico e contratual.
- Como BigDataCorp e Direct Data publicam tabela de preço por consulta com desconto por volume, esse é o modelo mais fácil de precificar uma oferta de revenda com margem simples ("compro a R$0,033–0,040, cobro do lojista R$0,15–0,30 embutido no plano do ERP").
- A ausência quase universal de tabela pública de comissão para reseller (idwall, CAF/Certta, Neoway, unico) sugere que esses contratos são negociados caso a caso e provavelmente exigem volume mínimo mensal e assinatura de contrato comercial + termo de tratamento de dados (LGPD) — não é um cadastro self-service como o da Serasa "Clube do Revendedor".

### Gaps
- Preço por consulta de idwall, CAF/Certta, unico Check e Neoway não está público — nenhuma fonte encontrada traz número em R$; requer contato comercial direto ou acesso ao dashboard logado.
- Estrutura de comissão/split do programa Reseller/Co-sell da idwall (percentual, volume mínimo, exclusividade) não encontrada em fonte primária.
- Requisitos formais de contrato e LGPD (DPA — Data Processing Agreement, prazo de retenção, finalidade declarada) para revender esses dados não foram encontrados detalhados em nenhuma das páginas acessadas nesta pesquisa; isso é uma lacuna relevante pois o objetivo pede esse dado explicitamente.
- Nenhum caso público e nomeado de "empresa que ganha dinheiro revendendo KYC de fulano" (fora dos próprios provedores) foi encontrado nesta rodada — os exemplos de "quem usa" (Votorantim, Original) são clientes finais, não revendedores/distribuidores.

## Negativação (Serasa, Boa Vista/Equifax, SPC) via API como revenda; protesto de títulos digital via API

### Takeaway
A Serasa Experian tem um programa de revenda **self-service e com números públicos concretos** (Clube do Revendedor: 10% de desconto ao cliente final + 15% de comissão ao parceiro por venda), mas isso parece mirar produtos de consumidor (limpa-nome, monitoramento), não necessariamente a API de negativação B2B. Para a API de negativação/consulta de score em si, o acesso comum de mercado é via distribuidores autorizados terceiros (ex.: Think Data, SOA Web Services), não diretamente da Serasa. Protesto de títulos via IEPTB/CENPROT tem múltiplos revendedores de API (Direct Data, Netrin, Infosimples), mas a **consulta pública de protesto por CPF/CNPJ é gratuita na fonte** — o que se cobra é a automação/API, não a informação em si.

### Cited Findings
- Serasa Experian tem um programa chamado **"Clube do Revendedor"**: cadastro simples, cupom de **10% de desconto** para o cliente final e **15% de comissão** ao parceiro a cada venda — [Serasa Experian — Blog Empresas](https://empresas.serasaexperian.com.br/blog/quer-fechar-uma-parceira-com-a-serasa-experian) (conteúdo obtido via snippet de busca; o fetch direto da página foi bloqueado pelo proxy de rede nesta sessão, então o número não pôde ser reconfirmado lendo a página inteira — tratar como preliminar).
- Existem distribuidores/integradores terceiros que vendem acesso à API da Serasa Experian: **Think Data** ("Distribuidor Autorizado Serasa Experian" para consulta de CNPJ e CPF) — [Think Data](https://www.thinkdata.com.br/serasa-experian/consulta-cnpj-cpf/); e **SOA Web Services**, que oferece "Negativação na Serasa Experian via API" e API de consultas Serasa Experian, Receita Federal, Sintegra, biometria facial, Correios, telecom — [SOA Web Services — Negativação](https://soawebservices.com.br/negativacao); [SOA Web Services — API Serasa](https://www.soawebservices.com.br/serasa-experian).
- Serasa Experian tem produto direto "Score e Atributos via API" — [Serasa Experian](https://www.serasaexperian.com.br/solucoes/score-e-atributos-api/) — mas sem preço público na página encontrada.
- Sobre protesto (IEPTB/CENPROT): a **consulta pública de protesto por CPF/CNPJ não tem taxa** na fonte oficial (é gratuita) — o que existe é cobrança pelos provedores de automação/API que dão acesso programático e agregam todos os cartórios do país numa chamada só — [resumo de busca sobre CENPROT/IEPTB](https://protestosp.com.br/); confirmado pela existência de players cobrando pela automação: **Direct Data** ("autorizada pelo CENPROT a revender consulta IEPTB", agrega todos os estados numa API) — [Direct Data — Protestos IEPTB](https://www.directd.com.br/protestos-ieptb); **Infosimples** (API de consulta IEPTB/CENPROT, exige login gov.br criado em pesquisaprotesto.com.br) — [Infosimples — IEPTB Protestos](https://infosimples.com/consultas/ieptb-protestos/); **Netrin** (API IEPTB/CENPROT para avaliar histórico de inadimplência em análise de crédito) — [Netrin](https://netrin.com.br/api/ieptb-cenprot-protestos/).
- Infosimples cobra por uso ("pay-per-use"), com **preço unitário decrescente conforme o volume mensal de consultas aumenta**, e algumas APIs têm um **preço adicional por chamada além do preço base**, quando há custo excepcional de automação no processo — [Infosimples — Preços](https://infosimples.com/consultas/precos/) (conteúdo por snippet; fetch direto bloqueado pelo proxy nesta sessão).
- Infosimples também automatiza CND Federal/PGFN, CND Estadual (SEFAZ) e CND Municipal (ex.: Salvador/BA) via web scraping/RPA sobre os portais oficiais — [Receita Federal/PGFN CND](https://infosimples.com/consultas/receita-federal-pgfn/); [SEFAZ Certidão Estadual](https://infosimples.com/consultas/sefaz-certidao-debitos/); [Prefeitura Salvador CND](https://infosimples.com/consultas/pref-ba-salvador-cnd/).

### Inferences
- Para um ERP entrar em "negativação via API como revenda", o caminho mais viável não é contrato direto com Serasa/Boa Vista/SPC (que normalmente exige porte e compliance maiores), e sim tornar-se cliente/revendedor de um agregador já homologado (Think Data, SOA Web Services, Direct Data, Infosimples, Netrin) e embutir a consulta no próprio produto com markup — modelo replicável com baixo atrito contratual.
- O negócio de "protesto online" não está em vender o dado (que é público e gratuito na fonte), mas em vender **conveniência/automação/agregação nacional via API** — a margem do revendedor vem do preço da automação, não de uma licença sobre o dado.
- O modelo "Clube do Revendedor" da Serasa (10%/15%) parece desenhado para canais de varejo/afiliados vendendo produtos de consumidor final (ex.: score, monitoramento, limpa-nome), não para uma integração B2B de API de negativação dentro de um ERP — são propostas de valor diferentes e não devem ser confundidas na síntese final.

### Gaps
- Não foi possível confirmar, lendo a página primária da Serasa Experian, se o "Clube do Revendedor" (10%/15%) cobre a API de negativação B2B ou é exclusivo de produtos de consumidor — página bloqueada pelo proxy de rede nesta sessão (`EGRESS_BLOCKED` para `empresas.serasaexperian.com.br`).
- Preço por consulta de negativação/score da Serasa Experian, Boa Vista/Equifax e SPC não encontrado publicamente em nenhuma fonte desta pesquisa (nem direto, nem via distribuidor) — normalmente exige negociação comercial e NDA.
- Não encontrei exemplos nomeados de empresas SaaS/ERP (fora dos próprios distribuidores como Think Data/SOA Web Services) que declarem publicamente faturar com a revenda dessas APIs de negativação/protesto.
- Requisitos formais (contrato de correspondente, convênio com SPC/Serasa, volume mínimo) não encontrados detalhados — o objetivo pedia isso explicitamente e ficou como lacuna.

## Cobrança/recuperação de crédito terceirizada via API (Acordo Certo, QueroQuitar, Paschoalotto, Monkey) e régua de cobrança via WhatsApp

### Takeaway
O modelo de ganho dessas plataformas de negociação de dívida é **success fee pago pelo credor** (banco/varejista), não pelo devedor — o serviço é gratuito para quem está negativado. Não encontrei tabela pública de percentual de comissão nem programa formal de "reseller de API" para Acordo Certo, QueroQuitar ou Paschoalotto; Paschoalotto tem um programa de parceiro de API voltado a oferta de crédito (não de cobrança). Não foi possível confirmar dados concretos sobre "Monkey" como provedor de régua de cobrança via WhatsApp nesta pesquisa.

### Cited Findings
- Acordo Certo: **serviço gratuito para o devedor**; a empresa ganha comissão das empresas credoras a cada acordo fechado com sucesso; tem parcerias com **mais de 50 instituições financeiras e empresas de diversos setores** — [Acordo Certo — LinkedIn](https://br.linkedin.com/company/acordo-certo); ver também análise de terceiro em [Financera](https://financera.com.br/analise/acordo-certo/).
- Existe também a marca "Acordo Recovery"/"Serasa Recovery", ligada ao ecossistema Serasa, para negociação de dívidas com desconto — [Serasa — blog Recovery/Acordo](https://www.serasa.com.br/limpa-nome-online/blog/recovery-acordo/) (relevante porque mostra que a própria Serasa também atua nesse elo da cadeia, e não só como bureau).
- QueroQuitar: mais de 10 anos no segmento de recuperação de crédito; ao pagar a primeira parcela do acordo, o nome pode ser limpo em 5 dias úteis; tem produto "Recovery" com **negociação de dívidas com até 98% de desconto** — [QueroQuitar](https://www.queroquitar.com.br/) e [QueroQuitar Recovery](https://www.queroquitar.com.br/recovery/).
- Paschoalotto atua **exclusivamente como prestadora terceirizada de tratamento/regularização de dívidas em atraso por conta de instituições parceiras** — não compra as dívidas nem detém cessão de crédito, é contratada pela instituição financeira credora que fornece os dados e autorizações — [busca sobre Paschoalotto](https://www.jusbrasil.com.br/busca?q=paschoalotto+assessoria+de+cobranca).
- Paschoalotto tem um programa "Seja nosso parceiro" com **API que parceiros integram aos próprios sistemas para oferecer crédito e aumentar receita**, sem o cliente sair da plataforma do parceiro para pedir crédito e receber a resposta da análise — [Paschoalotto — Seja nosso parceiro](https://emprestimo.paschoalotto.com.br/seja-nosso-parceiro). **Atenção: esse programa parece ser de originação/oferta de crédito, não de cobrança/recuperação terceirizada** — é preciso não confundir os dois produtos da mesma empresa na síntese final.
- Reclame Aqui tem múltiplas reclamações registradas contra a Paschoalotto por cobrança considerada indevida/abusiva por consumidores em nome de bancos como Santander e Bradesco — [Reclame Aqui — Paschoalotto](https://www.reclameaqui.com.br/paschoalotto-servicos-financeiros/) (múltiplas páginas). Isso é relevante como sinal de risco reputacional para quem for intermediar esse tipo de serviço white label.
- Não foi encontrada nenhuma informação confiável e específica sobre "Monkey" como plataforma de cobrança/régua via WhatsApp no Brasil nesta pesquisa — as buscas retornaram apenas resultados genéricos sobre precificação da API oficial do WhatsApp Business e uma ferramenta não relacionada chamada "CobroYa" (Mercado Pago + WhatsApp, projeto open source, não é a "Monkey" citada no objetivo) — [glama.ai/CobroYa](https://glama.ai/mcp/servers/dan1d/cobroya/inspect).
- Sobre a cobrança da própria API do WhatsApp (infraestrutura que sustenta qualquer régua de cobrança via WhatsApp): desde julho de 2025 o modelo mudou de "blocos de conversa" (24h) para **cobrança por mensagem enviada, segmentada por categoria** — [Z-API — blog](https://z-api.io/blog/api-do-whatsapp-muda-modelo-de-cobranca/); [Respond.io — WhatsApp API Pricing 2026](https://respond.io/blog/whatsapp-business-api-pricing/).

### Inferences
- O modelo de earning nessa vertical não é "preço por consulta de API", e sim **success fee sobre o valor recuperado ou por acordo fechado**, tipicamente pago pelo credor (banco, varejista, financeira) e não pelo consumidor. Isso muda o tipo de contrato que um ERP precisaria negociar: não é uma tabela de preço de API, é um contrato de parceria comercial com percentual de comissão negociado (o percentual em si não está público em nenhuma das três empresas pesquisadas).
- Como esse mercado tem forte exposição a reclamação de consumidor (Paschoalotto no Reclame Aqui), um ERP que for revender/embutir régua de cobrança terceirizada deveria tratar isso como risco de marca, não só como oportunidade de receita.
- "Monkey" pode ser uma marca menos relevante em 2026 ou meu conjunto de buscas não captou o termo certo (pode ser nome comercial diferente, ter mudado de marca, ou ser uma empresa pequena/regional pouco indexada) — recomendo ao escritor do relatório final não afirmar nada sobre "Monkey" além de que não foi encontrada evidência pública confiável.

### Gaps
- Percentual/estrutura de success fee de Acordo Certo, QueroQuitar e Paschoalotto não está público em nenhuma fonte encontrada — normalmente é definido em contrato bilateral com o credor, não divulgado.
- Nenhum programa formal de "reseller de API de cobrança" (no sentido de um ERP embutir a régua de outra empresa e ganhar comissão) foi encontrado documentado publicamente para essas três empresas.
- "Monkey" (citada no objetivo como exemplo) não pôde ser identificada com confiança nesta pesquisa — não há confirmação de que é uma empresa real de cobrança via WhatsApp no Brasil, nem dados sobre ela. Precisa de busca adicional com termo mais específico (ex.: nome completo da empresa, CNPJ, ou site oficial) que não foi encontrado nesta rodada.
- Nenhum caso público e nomeado de empresa terceira (fora as próprias operadoras) ganhando dinheiro como distribuidor/revendedor dessas soluções de cobrança foi encontrado.

## Emissão de boletos/Pix cobrança/Pix Automático — margem de revenda (Asaas, Efí, Iugu, subadquirência)

### Takeaway
Iugu e Asaas têm modelos públicos e claros de **subconta + white label + split de pagamento**, permitindo que uma plataforma (como um ERP) ofereça cobrança (boleto/Pix/cartão) sob a própria marca e capture uma fatia do valor via split, mas **as taxas de ponta a ponta que a plataforma cobra do lojista final não são públicas** — só a taxa que o PSP cobra da plataforma. Não encontrei dados de Efí (ex-Gerencianet) sobre programa de parceiro/subadquirência nesta rodada.

### Cited Findings
- Iugu oferece **Split de Pagamentos** que permite dividir automaticamente valores recebidos entre partes (parceiros, fornecedores, subcontas) por percentual ou valor fixo, com painel exclusivo por subconta para acompanhar vendas e transferência de comissões entre contas Iugu ou contas bancárias dos parceiros — [Iugu — Split de Pagamentos](https://www.iugu.com/split-pagamentos); [Iugu Docs — Split](https://dev.iugu.com/docs/split-de-pagamento).
- Iugu **White Label**: a Iugu fornece a plataforma para o cliente usar com a própria marca nas subcontas; a "fintech parceira" (Iugu) entrega infraestrutura pronta e personalizável, permitindo à empresa contratante aproveitar a experiência da Iugu mantendo a identidade do próprio negócio — [Iugu — Fintech white label](https://www.iugu.com/blog/fintech-white-label).
- Tabela de taxas encontrada para Iugu (via busca, não confirmada por fetch direto na página oficial de preços): **Pix 0,99%**, **boleto R$ 1,99**, **cartão entre 4,49% e 7,99% conforme tier**, **mensalidade de plataforma entre R$ 49 e R$ 499/mês** — citado a partir de conteúdo de terceiro ([SocialHub — blog](https://www.socialhub.pro/blog/cobranca-whatsapp-iugu-split-payment-subadquirente-marketplace-multi-conta-pme-brasil-2026/)); a página oficial [Iugu — Planos e Preços](https://www.iugu.com/planos) existe mas não pôde ser lida por completo nesta sessão — **tratar esses números como não confirmados na fonte primária**.
- Asaas: **subconta** é uma conta de pagamento vinculada à conta principal, destinada a clientes/parceiros do cliente Asaas, com acesso aos serviços Asaas através do vínculo com a conta-mãe; por padrão a subconta **herda as configurações da conta raiz** (taxas, permissões, white label) — [Asaas — Blog Subconta](https://blog.asaas.com/subconta-asaas/); [Asaas Docs — Criação de subcontas](https://docs.asaas.com/docs/criacao-de-subcontas).
- Asaas **White Label** é uma modalidade contratual em que a Asaas fornece a plataforma para o cliente usar com a própria marca nas subcontas, descrita como forma "menos custosa de desenvolver o negócio sem construir infraestrutura própria" — [Asaas — Blog Subconta](https://blog.asaas.com/subconta-asaas/).
- Split de pagamentos Asaas funciona sobre Pix, boleto e cartão, incluindo cobranças parceladas/recorrentes; **a taxa da Asaas é descontada antes da divisão entre as partes**, e o percentual do split é aplicado apenas sobre o valor líquido da cobrança — [Asaas — Split de pagamentos](https://blog.asaas.com/split-de-pagamento/); [Asaas Docs — Dúvidas frequentes Split](https://docs.asaas.com/docs/duvidas-frequentes-split).
- Criar subcontas pode gerar cobranças de taxas específicas — o valor exato depende do contrato de cada cliente Asaas, verificável apenas dentro do painel ("Configurações de Conta > Taxas") — [Asaas Docs](https://docs.asaas.com/docs/criacao-de-subcontas).

### Inferences
- O modelo real de ganho de uma plataforma (ERP) que revende cobrança via Asaas/Iugu é: contratar como conta-mãe, criar subcontas white label para os lojistas, e usar o split para reter uma fatia (ex.: alguns centavos por boleto, um spread sobre a taxa de Pix, ou uma taxa fixa de plataforma) — mas a margem líquida depende inteiramente da negociação de taxa que o ERP consegue como conta-mãe versus o que repassa ao lojista, e essa taxa negociada não é pública (varia por volume processado).
- Não há, nas fontes encontradas, nenhum número de "quanto uma plataforma ganha em média por boleto emitido" revendendo Asaas/Iugu — isso normalmente vem de um contrato de parceria/gateway negociado direto com o time comercial, fora das páginas públicas de preço padrão.

### Gaps
- Programa de parceiro/subadquirência da **Efí** (ex-Gerencianet) não foi pesquisado com sucesso nesta rodada (não incluído nas buscas por limite de chamadas) — fica como lacuna a preencher em pesquisa futura.
- Não encontrei a tabela oficial de preços da Iugu lida diretamente da página primária (bloqueio de rede) — os números de taxa citados vêm de uma fonte secundária (blog terceiro) e precisam ser confirmados antes de entrar no relatório final como fato.
- Nenhum exemplo nomeado e verificável de "empresa ganhando dinheiro revendendo boleto/Pix via Asaas/Iugu" foi encontrado nesta pesquisa (o caso "Pague Bem Brasil" apareceu como case de sucesso da Iugu mas não foi lido em detalhe).
- Margem exata (spread) que uma plataforma white label consegue reter por transação não está pública em nenhuma das duas empresas.

## Certidões automatizadas (CND federal, trabalhista, protesto, cartórios) e consulta de processos judiciais — preços de atacado e revenda

### Takeaway
Infosimples é o provedor mais claramente documentado publicamente para automação de certidões (CND federal/PGFN, estadual/SEFAZ, municipal) com **preço por uso decrescente por volume**, embora o valor exato em R$ não tenha sido lido diretamente da página de preços nesta sessão (bloqueio de rede). Para consulta processual, o Escavador tem plano de consumidor a partir de R$ 9,90/mês e uma "Escavador Business API" separada para uso em escala, com limite técnico de 500 requisições/minuto; não há preço público da API Business.

### Cited Findings
- Infosimples automatiza consultas de **CND Federal/PGFN** (débitos relativos a créditos tributários federais e dívida ativa da União, a partir de CPF ou CNPJ) — [Infosimples — Receita Federal/PGFN](https://infosimples.com/consultas/receita-federal-pgfn/); há também uma versão "2via" (segunda via de lista) — [Infosimples — PGFN 2via](https://infosimples.com/consultas/receita-federal-pgfn-2via-list/) — e uma versão "nova" — [Infosimples — PGFN nova](https://infosimples.com/consultas/receita-federal-pgfn-nova/).
- Infosimples também tem **CND Estadual (SEFAZ)** cobrindo todos os SEFAZ do Brasil a partir de CPF, CNPJ ou Inscrição Estadual — [Infosimples — SEFAZ Certidão de Débitos](https://infosimples.com/consultas/sefaz-certidao-debitos/); e produtos municipais específicos, como CND de Salvador/BA — [Infosimples — Prefeitura Salvador](https://infosimples.com/consultas/pref-ba-salvador-cnd/) — e do Piauí, incluindo solicitação de CNDA (Certidão Negativa da Dívida Ativa) — [Infosimples — SEFAZ PI CNDA](https://infosimples.com/consultas/sefaz-pi-cnda/) e visualização de certidão CND/CNDA — [Infosimples — SEFAZ PI Visualizar](https://infosimples.com/consultas/sefaz-pi-visualizar-cert/).
- Cobrança da Infosimples é **por uso ("pay-per-use")**, com **preço unitário decrescente automaticamente conforme aumenta o volume mensal de consultas**; algumas APIs têm um **valor adicional por chamada além do preço base**, cobrado apenas quando há custo excepcional de automação envolvido — [Infosimples — Preços das APIs de consulta](https://infosimples.com/consultas/precos/) (conteúdo obtido via resultado de busca; fetch direto da página bloqueado nesta sessão pelo proxy — **valores em R$ específicos não confirmados diretamente na fonte primária nesta rodada**).
- Escavador: planos de consumidor a partir de **R$ 9,90/mês** para acompanhar processos, com notificações em tempo real e resumos por IA ("escavAI") nos planos Padrão e Avançado — [Escavador — Preços](https://www.escavador.com/precos).
- Escavador Business API permite **consultar processos por CPF, CNPJ, OAB, nome ou número do processo**, com foco em empresas que precisam consultar/acompanhar processos em larga escala e funcionalidades de IA — [Escavador Business API](https://www.escavador.com/business/api); documentação técnica em [api.escavador.com/v1/docs](https://api.escavador.com/v1/docs/); SDK Python oficial em [GitHub — Escavador/escavador-python](https://github.com/Escavador/escavador-python).
- A API Business do Escavador tem **duas versões (V1 e V2)** — V1 com busca e monitoramento de processos, pessoas, empresas e diários oficiais — e um **limite técnico de 500 requisições por minuto** — [Judit.io — comparativo de APIs de consulta processual 2026](https://judit.io/blog/api-judit/api-consulta-processual-monitoramento-processual-fornecedores-brasil-escavador-api/).
- Existe um mercado concorrente/comparável de APIs de consulta processual no Brasil além do Escavador — pelo menos a Judit e outros players comparados num artigo de 2026 citando "6 plataformas" — [TrackJud — comparativo de 6 plataformas](https://trackjud.com.br/en/blog).

### Inferences
- O padrão de precificação "atacado decrescente por volume" (Infosimples, BigDataCorp, Direct Data, Iugu/Asaas via spread) é consistente em todo o setor de dados públicos automatizados no Brasil — sugere que qualquer modelo de revenda de um ERP deve ser desenhado como assinatura com franquia de consultas + excedente por unidade, replicando a própria estrutura dos fornecedores upstream.
- O Escavador tem dois produtos claramente distintos: um B2C/profissional liberal (R$ 9,90/mês) e um B2B de API em escala (Business API, sem preço público) — a oportunidade de revenda por um ERP provavelmente está no segundo, mas exige negociação comercial direta, não há tabela de "wholesale" pública.
- Não localizei, nesta pesquisa, dados de preço público para Jusbrasil API nem Digesto (citados no objetivo) — ambos parecem não publicar tabela de preço de API abertamente, reforçando o padrão do setor de negociação sob contato comercial.

### Gaps
- Preço específico em R$ por consulta de CND (federal, estadual, municipal) da Infosimples não foi confirmado lendo a página oficial de preços (bloqueio de rede `EGRESS_BLOCKED` para infosimples.com nesta sessão) — apenas a estrutura (pay-per-use, decrescente por volume, taxa adicional condicional) foi confirmada via resultado de busca.

- Preço/plano da API do **Jusbrasil** não encontrado — não pesquisado diretamente nesta rodada por priorização de tempo; possível lacuna a cobrir depois.
- Preço/plano da API da **Digesto** não encontrado — mesmo motivo.
- Preço público da Escavador Business API (por consulta ou por plano) não encontrado — provavelmente sob contato comercial.

## Consulta CPF/CNPJ/score para decisão de crédito B2B — margens de distribuidor

### Takeaway
O padrão claro do mercado é **desconto por volume com tabela pública de preço por consulta**, exemplificado pela BigDataCorp (R$ 0,033–0,040 para dado cadastral básico) e replicado estruturalmente por Direct Data e Infosimples (mecanismo de desconto por volume, sem valor exato confirmado por fonte primária nesta rodada). A margem de um distribuidor nesse mercado normalmente vem de comprar no atacado (grandes volumes, preço mais baixo) e vender no varejo (poucas consultas por cliente final, preço mais alto), sem tabela pública desse spread específico.

### Cited Findings
- BigDataCorp: dataset básico de pessoa física (CPF, nome, nascimento, nome da mãe) custa **R$ 0,040/consulta na faixa 1–10.000/mês**, caindo a **R$ 0,033/consulta na faixa 500.001–1.000.000/mês** — [BigDataCorp — Tabela de preços](https://docs.bigdatacorp.com.br/apps/docs/tabela-de-pre%C3%A7os).
- BigDataCorp disponibiliza uma **API de Preços própria e gratuita** para o cliente calcular antecipadamente o custo de qualquer combinação de datasets antes de consumir — [BigDataCorp — Guia API de Preços](https://docs.bigdatacorp.com.br/plataforma/docs/guia-api-de-pre%C3%A7os); [BigDataCorp — API de Preços (referência)](https://docs.bigdatacorp.com.br/plataforma/reference/api-de-pre%C3%A7os).
- BigDataCorp tem um **Data Marketplace** de datasets de parceiros dentro do mesmo padrão de qualidade/segurança/compliance da plataforma — abre espaço para um ERP revender também dados de terceiros integrados via BigDataCorp, não só dados próprios da empresa — [BigDataCorp — Preços e transparência](https://docs.bigdatacorp.com.br/apps/docs/pre%C3%A7os-e-transpar%C3%AAncia).
- Direct Data adota o mesmo padrão estrutural: **modelo pré-pago (sem contrato, sem mensalidade mínima) vs. pós-pago (onboarding assistido, SLA contratual)**, com desconto progressivo por volume, mirando explicitamente **fintechs, PMEs e times de compliance com necessidade de KYC/AML/PLD em escala** — [Direct Data — Preços](https://www.directd.com.br/precos) (via snippet, fetch direto bloqueado nesta sessão).
- Existem outras plataformas de consulta CPF/CNPJ com API que aparecem no ecossistema mas não foram aprofundadas nesta pesquisa: cpfcnpj.com.br, dbdireto.com.br, cpf-brasil.org — citadas nos resultados de busca como concorrentes diretos de Direct Data no nicho de consulta de Receita Federal — [cpfcnpj.com.br — API Receita Federal](https://www.cpfcnpj.com.br/api-receita-federal/); [dbdireto — Consulta API Receita Federal](https://dbdireto.com.br/consulta-api-receita-federal/).

### Inferences
- Um ERP que queira embutir "consulta CPF/CNPJ/score" no próprio produto tem pelo menos 4–5 fornecedores de atacado concorrentes entre si (BigDataCorp, Direct Data, Infosimples, cpfcnpj.com.br, dbdireto) com preços de entrada na casa de poucos centavos por consulta em baixo volume — isso cria uma janela de margem real: comprar a ~R$ 0,03–0,05/consulta no atacado e embutir no plano do ERP com markup de 3x–10x (comum em produtos SaaS de dado) ainda resultaria em um preço final competitivo (poucos centavos a poucos reais) para o lojista final.
- Como não há tabela pública de "quanto ganha o distribuidor" (spread), a estratégia mais segura para o relatório final é apresentar a margem como um **cálculo estimado a partir do preço de atacado publicado** (ex.: comprar a R$0,04, vender embutido a R$0,20–0,40 no plano do ERP), deixando claro que é uma estimativa do pesquisador e não um número divulgado por nenhuma empresa.

### Gaps
- Nenhuma das empresas pesquisadas (BigDataCorp, Direct Data, Infosimples) publica o preço de revenda/varejo recomendado ou a margem de um distribuidor formal — apenas o preço de atacado ao cliente final direto.
- Não encontrei programa formal e nomeado de "distribuidor autorizado" com contrato padrão e volume mínimo definido para nenhuma dessas três empresas (diferente da Serasa, que ao menos tem o "Clube do Revendedor" nomeado publicamente, mesmo que os detalhes de aplicabilidade à API B2B fiquem incertos, ver seção de negativação).
- Requisitos de LGPD específicos para revenda de dados de CPF/CNPJ (finalidade, base legal, retenção, DPA) não foram encontrados detalhados nas páginas públicas consultadas — provavelmente estão nos Termos de Uso/contrato de cada fornecedor, não nas páginas de preço/marketing indexadas por busca.

## Nota metodológica desta pesquisa

Vários domínios relevantes (`infosimples.com`, `www.directd.com.br`, `www.loja.serpro.gov.br`, `empresas.serasaexperian.com.br`) retornaram **`EGRESS_BLOCKED`** ao tentar leitura direta da página (WebFetch) nesta sessão — o proxy de rede do ambiente bloqueou o acesso a esses domínios especificamente. Todas as informações desses domínios citadas acima vêm de **snippets de resultado de busca (WebSearch)**, não de leitura completa da página primária. Isso é suficiente para orientar o relatório, mas qualquer número específico em R$ atribuído a esses domínios deveria, idealmente, ser reconfirmado por outra via (ex.: navegador, ou nova tentativa de fetch em outra sessão) antes de ser publicado como fato definitivo em material voltado ao público externo.
